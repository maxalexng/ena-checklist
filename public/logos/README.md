# Agency logos

Extracted from `legacy-prototype/submissions-register-MASTER.html`'s inline
`AGENCY_LOGO_BY_ID` base64 blob (one file per agency id: `bca.png`, `ura.png`, etc).
Referenced from `src/template/keys.ts` (`agencyLogoSrc`). Agencies with no real-world
logo (`admin`, `site`) intentionally have no file here and fall back to a plain
colored code badge in the UI.

`tfcc.png` is NetLink Trust's logo (public-domain text logo from Wikimedia Commons,
`File:Logo_of_Netlink_Trust.svg`). TFCC has no logo of its own, and NetLink Trust is the
TFCC member landed-house projects actually deal with for fibre.
